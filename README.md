Heet Oswal — Interactive Portfolio

Personal portfolio website for Heet Oswal, built as an interactive, character-driven web experience.

Live Website

heetresume.vercel.app

About

This portfolio presents Heet Oswal's education, experience, projects, technical skills, and professional links through a custom interactive interface.

The website is centered around a stylized character with interactive facial and eye animations that respond to the visitor and the page scroll.

Features
Interactive character-based Hero section
Cursor-following eye animation
Click/tap character interaction with facial expression
Scroll-based character movement
Responsive desktop and mobile layouts
Interactive project presentation
Experience and education sections
Technical skills section
Resume access
GitHub and LeetCode integration
Smooth page and section animations
Light visual theme with a custom color palette

Running Locally

Clone the repository:

git clone <repository-url>
cd <project-folder>

Install dependencies:

npm install

Start the development server:

npm run dev

The application will be available at the local development URL provided by Vite.

Build

Create a production build:

npm run build

Preview the production build locally:

npm run preview
Deployment

The portfolio is deployed using Vercel.
